[Math Problem]
__PROBLEM__

[Solution]
__TAGGED_RESPONSE__

Your task is to judge the solution paragraph by paragraph and return the result directly as JSON.

Output exactly one JSON object with:
- "step_labels": a mapping from paragraph index to 1 or 0
  - 1 means the paragraph is correct and remains logically valid given the previous paragraphs.
  - 0 means the paragraph is incorrect, unsupported, or depends on an earlier incorrect paragraph.
- "final_label": 1 if the final answer of the whole solution is correct, otherwise 0.

Rules:
- Output JSON only.
- Do not include any reasoning, explanation, analysis, or markdown code fences.
- The entire response must be a single valid JSON object that can be parsed by `json.loads`.
- "step_labels" must contain every paragraph index exactly once.
- Use only 1 or 0 for every label.
- If an earlier paragraph is wrong and a later paragraph relies on it, that later paragraph should also be 0.

JSON schema:
{
  "step_labels": {"0": 1, "1": 1, "2": 0},
  "final_label": 0
}
